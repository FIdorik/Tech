# Использованные данные

content.csv и navigation.json — неизменённые копии файлов из dataset. Разделитель CSV — точка с запятой. Данные прочитаны и вручную перенесены в index.html; браузер не загружает эти файлы. При обновлении dataset необходимо синхронизировать копии и HTML. Полное соответствие полей описано в основном README.
