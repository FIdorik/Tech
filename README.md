# Практическая работа №1

HTML и базовая CSS-разметка. Семантическая структура страницы.

Адаптивная информационная страница курса веб-разработки. По исходному dataset вручную перенесены шесть карточек, шесть строк таблицы и четыре пункта навигации; подключены оба SVG. Сборка и JavaScript не используются.

## Запуск

Откройте `index.html` в современном браузере. Сборка, Node.js и сервер для этой статической страницы не требуются. Файлы CSV и JSON по заданию можно прочитать отдельно и перенести данные в HTML вручную.

## Структура

- `index.html` — семантические разделы, якорная навигация и форма.
- `css/styles.css` — оформление, Flexbox, Grid и медиазапросы.
- `dataset/` — неизменённые исходники задания.
- `data/` — точные копии CSV и JSON, использованных для разметки.
- `images/` — точные копии logo.svg и cover.svg из dataset/assets.
- `example/` — предоставленный учебный пример; не используется как исходный код страницы.
- `docs/checklist.md` — проверки перед сдачей.
- `docs/git-commands.md` — команды коммитов и PR для самостоятельного выполнения.

Существующие `package.json` и `package-lock.json` с Sass сохранены. Sass в первой работе не используется, устанавливать npm-зависимости для запуска не нужно.

## HTML и CSS

Основная структура: `header`, `nav`, `main`, `section`, `aside`, `footer`. Каждая из шести карточек оформлена тегом `article`; заголовок связан через aria-labelledby. У страницы один `h1`, разделы имеют `h2`. Ссылка пропуска навигации переводит к основному содержимому. Навигация и подвал используют Flexbox, основные двухколоночные блоки — Grid. Карточки подготовлены для Flexbox с переносом строк. Используются `box-sizing: border-box`, ограничивающий контейнер, относительные размеры и медиазапросы на 900 и 720 px.

Поля формы связаны с `label`. Используются `email`, `number`, `select`, `textarea`, `required`, `minlength`, `maxlength`, `min`, `max`. Используются только встроенные ограничения HTML. При корректной отправке GET-параметры появляются в адресной строке и открывается уведомление через CSS `:target`. Обработчика заявок нет. Используйте вымышленные данные; при запуске через HTTP параметры также получает локальный сервер. Все визуальные стили находятся в отдельном CSS.

## Проверка

Проверьте страницу на ширинах 375, 768 и 1440 px, навигацию клавишей Tab, фокус, пустую форму, неправильный email, число участников вне диапазона 1–30 и корректное заполнение. В DevTools проверьте Console, Elements и Accessibility. Перенесите папку проекта и проверьте относительные пути к CSS и изображениям.

## Использование dataset

`content.csv` имеет разделитель `;` и поля `id`, `title`, `category`, `description`, `value`. Все шесть записей перенесены без изменения в карточки и таблицу. `id` используется в id заголовков карточек, `title` — в заголовках и вариантах формы, `category` — в метках, `description` — в описаниях. Назначение `value` в исходниках не объясняется, поэтому поле показано под нейтральным названием «Значение».

`navigation.json` задаёт четыре ссылки: «О курсе» → `about`, «Направления» → `tracks`, «Расписание» → `schedule`, «Регистрация» → `signup`. Они перенесены в HTML вручную. В dataset нет дат и времени: раздел «Расписание» содержит план тем в порядке CSV с явным пояснением. Загрузка JSON или CSV через JavaScript не нужна.

`assets/cover.svg` показан в первом разделе, `assets/logo.svg` — в подвале; у обоих заданы alt и размеры. Пути относительные. Исходные файлы dataset не изменены; копии в data и images побайтово совпадают.

## Статус проверки

Автоматически проверены структура HTML, уникальность id, якоря, соответствие карточек, строк таблицы и меню dataset, доступные имена полей, наличие локальных ресурсов и идентичность копий. Визуальная проверка и взаимодействие в браузере не выполнены: среда отклонила открытие file://. Ручные проверки перечислены в docs/checklist.md.
