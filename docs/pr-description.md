Реализована информационная страница курса веб-разработки для практической №1 на HTML и CSS. Из dataset перенесены четыре ссылки навигации, шесть карточек и шесть строк таблицы, подключены оба SVG. Форма использует встроенную валидацию HTML; обработка заявок не предусмотрена.

Добавлены Flexbox, медиазапросы, состояния фокуса, ссылка перехода к содержимому и README с запуском без сборки. Необъяснённое поле value сохранено как «Значение»; отсутствие дат в исходниках пояснено рядом с таблицей.

Проверка: структура HTML, ссылки, соответствие dataset и идентичность копий проверены автоматически. Визуальная проверка и сценарии в браузере остаются в docs/checklist.md: автоматическое открытие file:// отклонено средой.
